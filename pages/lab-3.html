Prototype Pollution

Explore how unsafe JavaScript object merging can affect inherited properties, then compare vulnerable and protected behavior.

CWE-1321 JavaScript Security Interactive Lab 03

01. The Vulnerability

Prototype Pollution occurs when untrusted input changes an object's prototype, causing other objects to inherit unexpected properties. This can affect security-sensitive application behavior.

This lab models the effect using isolated data. It does not change the browser's global Object.prototype.

03. Why It Matters

Prototype Pollution can influence authorization checks, application settings and feature flags when inherited properties are trusted.

04. The Fix

Reject dangerous property names such as __proto__, constructor and prototype. Use own-property checks and safe object containers for untrusted input.

Dangerous-key filtering Fixed 
if (["__proto__", "constructor", "prototype"].includes(key)) {
  continue;
}
