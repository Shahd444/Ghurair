OWASP A01: Broken Access Control CWE-639 Lab 01

01. The Vulnerability

Insecure Direct Object Reference (IDOR) occurs when an application exposes a reference to a resource but does not properly verify that the requesting user is authorized to access it.

For example, changing a profile identifier should not give one user access to another person's private data.
