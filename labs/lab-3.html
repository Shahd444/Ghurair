Prototype Pollution

Prototype Pollution is a JavaScript vulnerability where attackers manipulate object prototypes through unsafe handling of user-controlled properties. This can cause unrelated objects to inherit unexpected properties and change application behavior.

CWE: CWE-1321 — Improperly Controlled Modification of Object Prototype Attributes

OWASP: A08:2021 — Software and Data Integrity Failures

How the vulnerability works

JavaScript objects can inherit properties from other objects through their prototype. An unsafe recursive merge can allow an attacker to modify that prototype using the special property __proto__.

Vulnerable code

The problem is that the merge function does not check whether a property name is dangerous before using it. 

function unsafeMerge(target, source) {
  for (const key of Object.keys(source)) {
    if (source[key] !== null &&
        typeof source[key] === "object" &&
        !Array.isArray(source[key])) {

      target[key] = target[key] || {};
      unsafeMerge(target[key], source[key]);

    } else {
      target[key] = source[key];
    }
  }
}

Fixed code

The fix rejects dangerous property names and creates nested objects without inheriting from Object.prototype. 

const blockedKeys = new Set([
  "__proto__",
  "constructor",
  "prototype"
]);

function safeMerge(target, source) {
  for (const key of Object.keys(source)) {

    if (blockedKeys.has(key)) continue;

    const value = source[key];

    if (value !== null &&
        typeof value === "object" &&
        !Array.isArray(value)) {

      if (!Object.hasOwn(target, key) ||
          target[key] === null ||
          typeof target[key] !== "object" ||
          Array.isArray(target[key])) {
        target[key] = Object.create(null);
      }

      safeMerge(target[key], value);
    } else {
      target[key] = value;
    }
  }
}

Why does this matter?

If an attacker pollutes a shared prototype, other objects may inherit unexpected properties. In an application that relies on inherited properties for security decisions, this can contribute to privilege escalation or unexpected behavior.
